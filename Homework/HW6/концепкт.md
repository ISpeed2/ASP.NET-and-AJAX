# Концепция проекта

## Идея

`Shop Management API` — REST API для небольшого интернет-магазина. Проект
управляет каталогом товаров, а OpenAPI-документ делает контракт API
понятным для разработчиков и позволяет проверять методы через Swagger UI или
командную строку.

## Что реализовано

- просмотр списка товаров и товара по идентификатору;
- создание товара;
- проверка входных данных с ответом `ValidationProblem`;
- хранение демонстрационных данных в памяти;
- Swagger UI и `swagger/v1/swagger.json` для OpenAPI-контракта.

## Архитектура

Проект использует Minimal API: endpoint принимает HTTP-запрос, выполняет
операцию с каталогом в памяти и возвращает типизированный ответ. Swagger
описывает доступные endpoint'ы, параметры, тела запросов и ответы.

## Проверка из командной строки

Запуск:

```bash
dotnet run --project Homework/HW6/HW6.csproj --urls http://localhost:5086
```

Проверка OpenAPI-документа:

```bash
curl -i http://localhost:5086/swagger/v1/swagger.json
```

Проверка API:

```bash
curl -i http://localhost:5086/api/products
curl -i http://localhost:5086/swagger
```

Фактические скриншоты запуска и выполненных команд находятся в
[`docs/screenshots`](docs/screenshots) и также добавлены в `README.md`.
